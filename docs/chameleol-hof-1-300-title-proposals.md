# カメレオる 殿堂入り固有称号案（1〜300号）

> **採用済み：1〜300号の固有称号を殿堂入り一覧カードと認定証の実表示に適用しています。**

## 方針

- 50棟を正式にクリアしたプレイヤーの**殿堂入り登録番号（ordinal）**に、固有の称号を1つずつ対応させる。
- 番号は到達順の記録であり、1〜300号の称号に上下関係や性能差は付けない。章立ては発想の分類であり、階級ではない。
- 同じプレイヤーの自己ベスト更新・再プレイでも称号と登録番号は変えない。既存のプレイ回数・ランキング・名前・記録は変更しない。
- 300号より後は現行の「50棟完全踏破・殿堂入り怪盗」を暫定表示する（301号以降の称号は別途検討）。
- 「記念キリ番」バッジは廃止し、固有称号を一覧カードと認定証の両方に表示する。画面の表示は既存登録番号のみで決まり、スコア・プレイ回数・ユーザーの登録名は変更しない。
